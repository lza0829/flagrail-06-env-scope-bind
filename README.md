# 灰度轨

## 骨架

**开关版本入轨 → 分桶灰度下发 → 回读确认 → 失效/回滚互证**

皮：功能开关 / 配置灰度控制台。去皮是 **版本入轨 + 分桶下发 + 回读确认 + 命运互证**，不是配置 CRUD、不是 RBAC、不是发版审批闸。

## 环境域绑定（已落地）

桶域、票域、边缘域、授权凭证同票校验。站规 `跨域口径` 决定跨域行为的正确性口径：

- **授权豁免**（默认）：域不一致时，持有效且未过期的跨域授权可下发；票与回读均打跨域标记。
- **硬拦**：域不一致即拒发，即便持有效授权也不放行。

共同底线：**无有效授权 → 拒发且不落票；授权过期 → 拒发且不落票**（失败闭，不静默豁免）。
下发在同一写事务内完成「版本/分桶校验 → 域裁定 → 落票」，过期授权在并发抢发下也落不了票。

- 页面：`/环境域`（口径切换 · 夹具 · 核证 · 授权表可查过期 · 域裁证据）
- `GET /api/核证?票号=` 返回 `桶域 / 票域 / 授权号 / 跨域标记 / valid`
- `GET /api/跨域授权` 逐行给出 `过期 / 有效` 判定；`GET /api/域裁` 为拒发/放行证据
- 夹具：`环域无授权跨域` · `环域授权后跨域` · `环域同域对照` · `环域授权过期并发` · `环域硬拦口径`
- 自动化：`python scripts/环境域验证.py`（起临时库自验，32 项断言）
